# 政党・候補者データの登録方針

このディレクトリには、照合に使用する政党・候補者の回答データを保存します。

## 絶対ルール
- 出典を確認できない回答を登録しない。
- マニフェストの記述を、アンケート回答であるかのように扱わない。
- 回答の意味を選択肢へ対応付ける根拠が弱い場合は、無理に分類せず `null`（未確認）にする。
- 回答がない項目を不一致として扱わない。
- 各データに出典URL、資料名、対象選挙・対象時点、確認日を持たせる。
- スコアは「一致数 / 比較可能数」で計算し、比較可能数を必ず併記する。
- 政党単位の回答と候補者個人の回答を混在させない。

## 推奨データ形式

```json
{
  "schemaVersion": 1,
  "datasetName": "政党公式アンケート回答",
  "election": null,
  "checkedAt": null,
  "parties": [
    {
      "id": "party-id",
      "name": "政党名",
      "sourceType": "official_questionnaire",
      "sourceUrl": "https://example.jp/",
      "sourceTitle": "資料名",
      "answers": {
        "question-id": {
          "choiceIndex": 0,
          "evidence": "回答の該当箇所または短い要約",
          "sourceUrl": "https://example.jp/"
        }
      }
    }
  ]
}
```

`choiceIndex` は設問の選択肢に対応する整数です。判断できない場合は項目自体を省略します。実在のデータを追加する前に、設問文・選択肢との対応を人手で検証してください。

## 公約資料インデックス
`manifestos.json` に、第51回衆院選で公約・政策資料を公開した主要11政党の公式資料リンクを登録しています。減税日本・ゆうこく連合は、両団体の資料を分けて登録しています。早稲田大学デモクラシー創造研究所の比較ページと、難民支援協会の分野別比較は補助資料として登録し、公式公約と混同しません。

## 現在の状態
質問ごとの初心者向け解説は `answer.html` に実装済みです。公式公約の資料リンクは登録済みですが、全資料の全文確認・政策項目の構造化・22設問との対応付けは作業中です。確認できた政策だけを照合データにし、未確認は未確認のまま扱います。したがって、検証が終わるまでは政党別の一致率を表示しません。

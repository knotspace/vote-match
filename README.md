# ボートマッチ｜政策比較

独立した政策比較・ボートマッチのプロジェクトです。

## 公開先
GitHub Pages を有効にすると、通常は `https://knotspace.github.io/vote-match/` で公開できます。

## 現在の実装
- トップ・回答・結果・説明ページを分離
- スマートフォン対応の回答フロー
- 6テーマ・全22問（テーマ選択に対応）
- 各設問に「詳しく！」の補足説明
- 回答の保存・再開・一覧確認
- 回答はブラウザ内（localStorage）に保存
- 政党比較は2026年衆院選の公約から対応づけ可能な15設問のみ参考一致率を算出
- 比較対象数・政策要約・政党公式資料へのリンクを表示
- 選挙区候補者データは未登録。候補者一致率は表示しない

## 比較データの注意
現在の一致率は、政党が当サイトの質問に回答した公式アンケートの結果ではありません。2026年衆院選の公約の記述を選択肢に対応づけた参考値です。公約の表現と質問の選択肢が完全一致しない場合や根拠を確認できない場合は、比較対象外にします。現時点では22問中15問に比較データを登録しています。未登録の7問は設問の意味と公約が正確に対応しない、または一次資料で十分な根拠を確認できないため、無理に採点していません。

## データを追加するときのルール
1. 公式の選挙公約・政策集・公式アンケート回答を一次資料として確認する。
2. 設問ごとに出典URL、資料名、対象選挙、確認日を記録する。
3. 公約の要約と公式アンケート回答を同じものとして扱わない。
4. 党の立場が明確でない場合は推測せず「未確認」とする。
5. 比較可能な設問数を必ず表示し、未回答・未確認の項目を分母に含めない。
6. 候補者別の比較は候補者本人の公開回答など根拠がある場合に限る。

# VOTE MAP

独立した政策比較・ボートマッチのプロジェクトです。

## 公開先
GitHub Pages を有効にすると、通常は `https://knotspace.github.io/vote-match/` で公開できます。

## 現在の実装
- スマートフォン対応のダークUI
- 6テーマ・12問の回答フロー
- 回答の戻る／修正／最初からやり直し
- 回答内容はブラウザ内だけで処理し、サーバー送信・保存はしない
- 政党回答データが未検証の段階では、一致率・順位を表示しない

## 政策データを追加するときのルール
1. 政党の公式政策・公約・公式アンケート回答を一次資料として確認する。
2. 設問ごとに出典URL、資料名、公開日または確認日を記録する。
3. 党の立場が明確でない場合は推測せず「明記なし」「確認できず」とする。
4. 政策の一致度は計算方法を公開し、回答しない項目は分母から除外する。
5. 政党名・掲載対象は対象選挙や時点を明記し、過去の選挙データを現行方針として扱わない。
6. 結果は参考情報として提示し、投票先を推奨・誘導しない。
